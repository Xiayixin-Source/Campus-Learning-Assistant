作品名称：校园学习助手（Campus Learning Assistant）
 
一、作品概述
 
本作品是基于uni-app开发的面向大学生的轻量化AI学习辅助网页应用。软件集成学习计时、课程学习模拟、在线考试、学习建议生成等功能，帮助学生管理学习任务，模拟练习自测。项目前端采用uni-app框架开发，支持浏览器直接打开使用，内置离线演示模式，无需后端服务即可体验全部基础功能。
 
二、AI工具使用说明
 
在项目开发全过程中，合理利用AI工具作为辅助，核心逻辑、页面设计、业务代码均由本人理解并人工修改、调试完成，AI仅作为辅助工具，没有直接交付完整成品。
 
1. 需求与方案设计阶段
使用AI辅助梳理项目功能需求，划分模块（学习模块、考试模块、信息展示模块），生成初步产品思路。本人结合大学生学习场景，对AI给出的方案进行删减、调整，确定最终功能清单。
​
2. 代码开发阶段
利用AI学习uni-app语法、调试报错代码，生成基础组件模板；针对双向链表、类与接口等C#/前端知识点，借助AI理解算法逻辑。所有AI生成的代码片段，均经过人工逐行阅读、修改、测试，修复bug，适配本项目业务逻辑，保证代码可正常运行。
​
3. 文档与素材辅助
借助AI辅助撰写项目说明、整理大赛材料，生成项目英文名称、README介绍文字；图片素材由本人截图产出，AI不参与界面视觉设计。
​
4. 演示内容辅助
AI辅助生成学习建议文本内容，作为应用内功能展示素材，文本内容经过人工审核修改。
 
三、人工优化思路
 
AI产出内容存在通用性强、贴合项目场景不足、存在潜在bug等问题，本人做了大量人工优化工作：
 
1. 代码层面
AI生成的初始代码存在边界漏洞、样式错乱问题。本人在HBuilderX环境反复调试，修复换行、组件渲染问题，完成项目打包，产出可独立运行的h5静态网页，保证任意电脑打开html文件就能正常浏览作品。
​
2. 功能层面
AI给出的功能方案偏理想化，我简化了复杂后端依赖，改为离线模式，适配本次大赛作品展示需求；调整学习时长计算逻辑、考试得分逻辑，贴合真实学生使用场景。
​
3. 界面与交互
参考古简约风格，人工调整页面布局、文字排版，优化按钮交互逻辑，保证界面简洁易用。
​
4. 内容层面
对AI生成的学习建议文案人工润色，去除空洞内容，贴合大学生课程学习场景。
 
四、作品创新亮点
 
1. 轻量化离线应用
基于uni-app打包为静态网页，不需要部署服务器，打开网页即可使用，部署门槛低，适合在校学生快速使用。
​
2. 多模块一体化学习
整合学习时长统计、课程学习、模拟考试、学习建议四大模块，一站式完成学习记录与自测。
​
3. 低门槛二次扩展
项目代码结构清晰，开源托管于GitHub，后续可以继续扩展题库、学习计划等功能，扩展性强。
 
五、实践应用价值
 
本作品面向高校学生，可用于日常自主学习记录、课前课后自测练习。帮助学生量化学习时长，及时检验学习效果，获取针对性学习建议。项目采用前端技术实现，对设备要求低，在电脑浏览器即可使用，有较强实用性。
 
六、总结
 
本项目合理使用AI作为开发辅助工具，做到AI辅助，人为主导。AI承担思路启发、代码模板参考、知识点答疑的工作；作品整体架构、功能取舍、代码调试、界面优化、材料撰写均由本人独立完成，完成从需求设计、编码开发到打包部署的完整开发流程。
